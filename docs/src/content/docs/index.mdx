## Launch In 60 Seconds

```bash
git clone https://github.com/nikomatt69/polytui-dashboard
cd polytui-dashboard
bun install
bun run dev
```

## Daily Operator Loop

1. Scan markets using categories, search (`/`), and watchlist filter (`f`).
2. Open order form with `o` (buy) or `s` (sell), validate, then `Enter` to submit.
3. Verify fills in order history (`h`) and adjust exposure in portfolio (`p`).
4. Keep alerts (`z`), automation rules (`b`), and AI assistant aligned with active strategy.
